# Plan: Замена BlockEditor sidebar на Drawer (шторку)

## Контекст

Вместо правой боковой панели BlockEditor редактирование блока теперь открывается через **шторку (Drawer)** из `components/ui/Drawer`. Шторка открывается по клику на иконку редактирования, которая появляется на блоке в холсте. Правую панель (sidebar) BlockEditor — убрать.

---

## Чеклист задач

### 1. Подготовка — изучи существующий код

- [ ] Открой `components/ui/Drawer` и изучи его API: какие пропсы принимает, как управляется открытие/закрытие (скорее всего через `open` + `onOpenChange` или аналог). Используй компонент строго по его существующему интерфейсу.
- [ ] Посмотри на текущую реализацию `AdminPanel` и `BlockEditor` — они будут изменяться.

---

### 2. Убери правую боковую панель из AdminPanel

- [ ] Удали из layout AdminPanel третью колонку (правую панель с `BlockEditor`).
- [ ] Удали из state переменную `selectedBlockId` — она больше не нужна для управления боковой панелью.
- [ ] Layout теперь снова двухколоночный:
  ```
  [ Левая панель (палитра) ] [ Холст (canvas) ]
  ```

---

### 3. Добавь иконку редактирования на каждый блок холста

- [ ] На каждом блоке, размещённом на холсте, добавь кнопку с иконкой редактирования (карандаш). Иконку возьми из библиотеки иконок, уже используемой в проекте (проверь `package.json` и существующий код — например `lucide-react`).
- [ ] Кнопка с иконкой располагается поверх блока — например, в правом верхнем углу (Tailwind: `absolute top-2 right-2`). Убедись, что блок имеет `relative` позиционирование.
- [ ] Кнопка НЕ должна конфликтовать с DND: повесь на кнопку `e.stopPropagation()` в обработчике `onClick`, чтобы клик не инициировал перетаскивание.

---

### 4. Добавь state для управления Drawer

- [ ] В `AdminPanel` добавь в state:
  ```ts
  const [drawerOpen, setDrawerOpen] = useState(false);
  const [editingBlock, setEditingBlock] = useState<PlacedBlock | null>(null);
  ```
- [ ] При клике на иконку редактирования блока:
  1. Установи `editingBlock` в данные этого блока.
  2. Установи `drawerOpen` в `true`.
- [ ] При закрытии Drawer (через `onOpenChange` или аналог): установи `drawerOpen` в `false`. `editingBlock` можно сбросить в `null` после закрытия анимации (или сразу — на усмотрение).

---

### 5. Встрой Drawer в AdminPanel

- [ ] Импортируй компонент `Drawer` (и нужные его части — `DrawerContent`, `DrawerHeader`, `DrawerTitle` и т.д.) из `components/ui/Drawer`.
- [ ] Добавь `Drawer` в JSX `AdminPanel`. Управляй им через `drawerOpen` и `setDrawerOpen`:
  ```tsx
  <Drawer open={drawerOpen} onOpenChange={setDrawerOpen}>
    <DrawerContent>
      {editingBlock && (
        <BlockEditor block={editingBlock} onSave={handleBlockSave} onClose={() => setDrawerOpen(false)} />
      )}
    </DrawerContent>
  </Drawer>
  ```
- [ ] Адаптируй пропсы под реальный API компонента `Drawer` из `components/ui/Drawer` (он может отличаться — смотри его исходный код).

---

### 6. Обнови компонент BlockEditor

- [ ] Убери из `BlockEditor` кнопку «Закрыть» / крестик, если закрытие теперь обрабатывается самим `Drawer`.
- [ ] Оставь кнопку **«Применить»** — она сохраняет данные формы через `onSave`.
- [ ] Убедись, что при открытии Drawer форма реинициализируется с актуальными `props` выбранного блока. Для этого передай `key={editingBlock.id}` на компонент `BlockEditor` — это заставит React пересоздать его при смене блока:
  ```tsx
  <BlockEditor
    key={editingBlock.id}
    block={editingBlock}
    onSave={handleBlockSave}
    onClose={() => setDrawerOpen(false)}
  />
  ```

---

### 7. Обнови обработчик сохранения в AdminPanel

- [ ] Обработчик `handleBlockSave(id, props)` обновляет `props` нужного блока в state холста (найди блок по `id`, замени его `props`).
- [ ] После сохранения Drawer **не закрывается** — пользователь может продолжить редактирование.
- [ ] Обнови также `editingBlock` в state, чтобы форма отражала свежие данные после сохранения.

---

### 8. Финальная проверка

- [ ] Правая боковая панель полностью убрана из layout.
- [ ] На каждом блоке холста видна иконка редактирования (карандаш).
- [ ] Клик по иконке открывает Drawer с формой для данного блока.
- [ ] Форма предзаполнена текущими `props` блока.
- [ ] Кнопка «Применить» сохраняет изменения в state, Drawer остаётся открытым.
- [ ] При смене блока (открытии Drawer для другого блока) форма корректно обновляется.
- [ ] Drawer закрывается стандартным способом (свайп / клик вне области / крестик самого Drawer).
- [ ] Иконка редактирования не мешает DND (stopPropagation проставлен).
- [ ] Кнопка «Сохранить» в AdminPanel выводит `console.log` с актуальными `props` всех блоков.
- [ ] Нет TypeScript-ошибок.
- [ ] Не добавлено ни одной новой зависимости.
