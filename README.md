# 💍 Свадебное приглашение

Привет! Это инструкция к вашему сайту-приглашению. Я постарался написать её так, чтобы можно было запустить и отредактировать сайт, даже если вы никогда раньше не программировали.

---

## 🚀 Шаг 1. Подготовка (делается один раз)

Прежде чем начать, нужно установить две программы, чтобы компьютер мог работать с кодом.

1.  **Скачайте и установите Node.js** (это "движок" для сайта).
    * Перейдите на [официальный сайт](https://nodejs.org/).
    * Скачайте версию **LTS** (Recommended for most users).
    * Установите её, нажимая "Далее" (Next) во всех окнах.
1.5. Проверьте установку:
```bash
    npm -v
    node -v
```
2**Скачайте редактор кода VS Code** (в нем удобно менять текст).
    * [Скачать тут](https://code.visualstudio.com/).
    * Тоже просто установите как обычную программу.
---

## 🛠 Шаг 2. Запуск сайта у себя на компьютере

1.  Откройте папку с проектом.
2.  Нажмите правой кнопкой мыши в пустом месте папки и выберите **"Open in Terminal"** (или "Открыть в терминале"). Если такой опции нет, откройте VS Code, перетащите туда папку проекта, и в верхнем меню выберите `Terminal -> New Terminal`.
3.  В появившемся черном окне введите команду для установки всех библиотек (это займет минуту):
    ```bash
    npm install
    ```
4.  Когда установка закончится, запустите сайт командой:
    ```bash
    npm run dev
    ```
5.  Вы увидите надпись вроде `Ready in ... ms`. Теперь откройте браузер и перейдите по адресу:
    👉 **http://localhost:3000**

Ура! Сайт работает локально.

## 📝 Шаг 3. Как менять текст и настройки

Вся конфигурируемая информация на сайте (имена, даты, карта, вопросы в анкете) хранится в одном главном файле config/app-config.json

### 1. Общие настройки (`shared`)
Здесь меняются главные данные свадьбы.
* `date`: Дата в формате 20.06.2026.
* `wifeName` / `husbandName`: Имена жениха и невесты.
* `textDate`: Дата текстом, которая будет красиво отображаться.

### 2. Блоки сайта (`layout`)
Сайт строится из блоков, которые идут друг за другом. У каждого блока есть `contentType` (тип блока) и `content` (содержимое).

#### 📍 Место проведения (`PLACE`)
Блок с картой.
* `title`: Заголовок (например, "Торжественная церемония").
* `address`: Адрес текстом.
* `startTime`: Время начала.
* `mapSettings`:
    * `coordinates`: Координаты для карты [широта, долгота]. Их можно взять на Яндекс.Картах (кликнуть правой кнопкой "Что здесь?").
    * `yandexMapUrl`: Ссылка на Яндекс.Карты, чтобы гость мог построить маршрут.
    * `hint`: Подсказка при наведении на точку.

#### 🕒 Тайминг (`TIMINGS`)
Расписание дня.
* `plan`: Список событий.
    * `event`: Название (например, "Торт").
    * `startTime`: Время.
    * `icon`: Иконка события (путь к файлу).

#### 👗 Дресскод (`DRESSCODE`)
Палитра цветов для гостей.
* `colorSchema`: Список цветов.
    * `color`: Код цвета (например, `#FFD1DC`). Можно найти в гугле по запросу "color picker".
    * `maleDressCodeImg` / `femaleDressCodeImg`: Картинки-примеры одежды.

#### 📋 Анкета гостя (`FORM`)
Опросник, который заполняют гости.
* `type`: Тип поля (`input` - текстовое поле, `radio_group` - выбор одного варианта, `checkbox_group` - выбор нескольких).
* `required`: `true` если поле обязательно для заполнения.
* `label`: Сам вопрос (например, "Что будете пить?").
* `fields`: Варианты ответов (для выбора).


#### 📋 Календарь (`CALENDAR`)
Календарь с вашей свадебной датой.

#### Прощальный блок (footer)
```
type GenderConfig = {
  maleEnding: string;     // например "ой"
  femaleEnding: string;   // например "ая"
  pluralText: string;     // например "дорогие"
  singleBase: string;     // например "дорог"
};

export interface IFooter {
  baseText?: string;           // например "До встречи"
  genderConfig?: GenderConfig;
  disableGenderEnding?: boolean; // если true — всегда одинаковая форма
  alwaysText?: string;         // если нужно полностью переопределить обращение
  pairSeparator?: string;      // например " & "
}
```

## 🖼 Шаг 4. Где хранить картинки

Все картинки должны лежать в папке **`public`**.

Например, если в конфиге написано:
`"markerIcon": "/images/Shelby.png"`

Это значит, что файл `Shelby.png` должен лежать в папке `public/images/`.
Просто закидывайте свои фото в эту папку и прописывайте пути к ним в конфиге.

## 📊 Шаг 5. Подключение Google Таблицы (для ответов гостей)

Чтобы ответы из анкеты (кто придет, что будут пить) автоматически попадали в удобную Excel-табличку, нужно создать "робота" и дать ему доступ к вашему файлу. Не пугайтесь, это выглядит страшно, но делается всего один раз за 5 минут.

### 1. Создаем таблицу
1.  Создайте новую **Google Таблицу** на своем гугл-диске.
2.  Назовите её, например, "Свадьба - Ответы".
3.  Скопируйте **ID таблицы** из адресной строки браузера.
    * Ссылка выглядит так: `docs.google.com/spreadsheets/d/`**`ВОТ_ЭТОТ_ДЛИННЫЙ_НАБОР_БУКВ_И_ЦИФР`**`/edit...`
    * Сохраните этот ID в .env переменную SPREAD_SHEET_ID.

### 2. Настраиваем "Робота" (Google Cloud)
1.  Зайдите на сайт [Google Cloud Console](https://console.cloud.google.com/).
2.  Сверху слева нажмите на выбор проекта (Select a project) -> **New Project** (Создать проект).
3.  Назовите его `Wedding` и нажмите **Create**. Подождите пару секунд, пока он создастся, и выберите его.

### 3. Включаем доступ к таблицам
1.  В строке поиска сверху введите: `Google Sheets API`.
2.  Нажмите на найденный результат и нажмите кнопку **Enable** (Включить).

### 4. Создаем ключи доступа
1.  Слева в меню выберите **Credentials** (Учетные данные).
2.  Нажмите сверху **+ CREATE CREDENTIALS** -> **Service Account** (Сервисный аккаунт).
3.  Придумайте имя (например, `wedding-bot`). Нажмите "Create and Continue", остальные поля можно пропустить и нажать "Done".
4.  В списке появится ваш новый аккаунт. Скопируйте его странный **Email** (он выглядит как `wedding-bot@...iam.gserviceaccount.com`).
5.  **ВАЖНО:** Вернитесь в свою Google Таблицу -> Нажмите кнопку **Настройки доступа (Share)** -> Вставьте этот Email -> Убедитесь, что стоит роль **Редактор** -> Нажмите "Отправить".
    *(Теперь наш робот имеет право писать в вашу таблицу)*.

### 5. Скачиваем ключ-файл
1.  Вернитесь в Google Cloud Console, в раздел Service Accounts.
2.  Нажмите на карандашик (или на email аккаунта), чтобы зайти в его настройки.
3.  Перейдите на вкладку **KEYS** (Ключи).
4.  Нажмите **ADD KEY** -> **Create new key**.
5.  Выберите формат **JSON** и нажмите **Create**.
6.  На компьютер скачается файл. **Это секретный ключ от вашего робота!**

### 6. Вставляем ключ в проект
1. Создайте в корне файл .env, скопируйте в него данные из файла .env.example.
2. Необходимо взять данные со скаченного ранее json и подставить их в .env файл в соответствующие ключи.
3. По умолчанию наименования таблица Sheet1, но можно изменить :)

### 🔑 Шаг 6.5. Предоставление прав доступа (Критически важно!)

1. Перейдите по ссылке: https://console.cloud.google.com/apis/api/sheets.googleapis.com/metrics?project=айди_вашего_проекта
2. Выдайте необходимые права.
